# Real-Time Location Tracker with Streamlit

Educational app to demonstrate geolocation in web apps using Python, Streamlit, and Folium.

## Features
- Input your phone number (demo only).
- Get real GPS coordinates from your device.
- Show interactive map with position and accuracy circle.
- Reverse geocoding to approximate address.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
